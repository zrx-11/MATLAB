这门课学什么？本手册怎么用？

《高等数学》（食品专业版）配套的“数学实验”课，目标不是让你背公式，而是用 MATLAB 这把“计算器+画图板”，把高数里的概念亲手算出来、画出来、验证出来。

手册结构一览

  1. 第 1 章：MATLAB 基础语法 —— 变量、函数、矩阵、流程控制、绘图，零基础起步；
  2. 第 2~5 章：高等数学四大主题实验 —— 极限、导数、积分、微分方程与级数，每条命令配代码与运行结果；
  3. 第 6 章：食品专业综合应用 —— 冷却、细菌增殖、营养降解、加工优化、质检数据，把数学用起来；
  4. 第 7 章：实验报告模板 + 附录命令速查表。
  5. 各章练习与解答、期末模拟卷与补充习题：选自三份配套习题册，题号沿用原书编号，附参考答案与程序。
建议路径：先跟着第 1 章把命令亲手敲一遍 → 再按章节做实验 → 第 6 章选 2~3 个案例写进实验报告。
每个代码块右上角都有“复制”按钮，复制后粘贴到 MATLAB 命令窗口或脚本文件中即可运行。结果以 MATLAB R2020b 及以上版本为准，低版本个别函数（如 integral）需注意版本。

1.5 数组与矩阵

MATLAB 名字就来自 “Matrix Laboratory”，矩阵/数组是它的核心。高等数学实验里，我们常用数组存函数值、画曲线。三种常用构造方式：

  • 冒号 a:h:b：从 a 到 b、步长 h 的一组数；
  • linspace(a,b,n)：在 a 与 b 之间均匀取 n 个点（含端点）；
  • 方括号 [ ]：直接列举，逗号/空格分隔列，分号分隔行。

z = [1 2 3; 4 5 6] % 2行3列矩阵
A = zeros(2,3)     % 2×3 全零矩阵
B = ones(1,4)      % 1×4 全一矩阵

数组的“逐元素运算”是画函数曲线的关键：用 .*、.^、./ 对每个元素分别运算。

1.6 流程控制

程序要“按条件分支”和“重复计算”，靠 if 和 for/while。这是写实验代码（比如分段函数、累加求和）的基础。

if 分支结构

MATLAB — if 语句（分段函数）
x = 3;
if x > 0
    y = x^2;
elseif x == 0
    y = 0;
else
    y = -x;
end
disp(y)   % 9

     9

→

→

分支一：x>0 时 y=x²；否则进入 elseif 判断 x==0 或 else 分支。

for 循环与求和

MATLAB — for 循环（计算 1+2+…+100）
s = 0;
for i = 1:100
    s = s + i;
end
disp(s)   % 5050
运行结果
        5050
验证结果：1+2+…+100 = 100×101/2 = 5050。用公式算一遍能立刻确认程序没写错——这就是“验证”环节。

while 循环

MATLAB — while 循环（累加到超过 1000 为止）
s = 0; i = 1;
while s <= 1000
    s = s + i;
    i = i + 1;
end
fprintf('i = %d, s = %d\n', i, s);
运行结果
i = 46, s = 1035
while 必须保证循环条件最终能变为假，否则会“死循环”卡死程序。不小心卡住了按 Ctrl+C 中断。

1.7 脚本文件与函数文件

实验内容多了以后，把代码写进 脚本文件（.m），点运行一次执行完，方便修改和保存。更规范的是写函数文件：把一段计算封装成“黑箱”，输入参数、输出结果，可反复调用。

MATLAB — 函数文件示例 myfun.m
function y = myfun(x)
% 计算 y = x^3 - 2x + 1
y = x.^3 - 2.*x + 1;
end
调用方式与运行结果
>> myfun(2)
ans =
     5

>> myfun([1 2 3])
ans =
     0     5    22
函数文件名必须与函数名一致（如 myfun.m），且不能以数字开头。% 开头是注释，不执行，用来写说明。

1.8 基础绘图

“画图”是数学实验最直观的验证手段。核心命令是 plot（对离散数据点连线）和 fplot（直接画符号函数/函数句柄，自动取点）。

plot(x, y, 'LineWidth', 2)   % 画曲线，线宽2
xlabel('x'); ylabel('y');    % 轴标签
title('y = sin(x)');         % 标题
grid on                      % 显示网格

概论、界面与帮助

1.1与其他计算机语言相比较，MATLAB 语言突出的特点是什么？

MATLAB 具有功能强大、使用方便、输入简捷、库函数丰富、开放性强等特点。

1.2MATLAB 系统由哪些部分组成？

MATLAB 系统主要由开发环境、MATLAB 数学函数库、MATLAB 语言、图形功能和应用程序接口五个部分组成。

1.4MATLAB 操作桌面有几个窗口？如何使某个窗口脱离桌面成为独立窗口？又如何将脱离出去的窗口重新放置到桌面上？

在 MATLAB 操作桌面上有五个窗口，在每个窗口的右上角有两个小按钮，一个是关闭窗口的 Close 按钮，一个是可以使窗口成为独立窗口的 Undock 按钮，点击 Undock 按钮就可以使该窗口脱离桌面成为独立窗口，在独立窗口的 view 菜单中选择 Dock……菜单项就可以将独立的窗口重新放置到桌面上。

1.5如何启动 M 文件编辑/调试器？

在操作桌面上选择“建立新文件”或“打开文件”操作时，M 文件编辑/调试器将被启动。在命令窗口中键入 edit 命令时也可以启动 M 文件编辑/调试器。

1.6存储在工作空间中的数组能编辑吗？如何操作？

存储在工作空间的数组可以通过数组编辑器进行编辑：在工作空间浏览器中双击要编辑的数组名打开数组编辑器，再选中要修改的数据单元，输入修改内容即可。

1.7命令历史窗口除了可以观察前面键入的命令外，还有什么用途？

命令历史窗口除了用于查询以前键入的命令外，还可以直接执行命令历史窗口中选定的内容、将选定的内容拷贝到剪贴板中、将选定内容直接拷贝到 M 文件中。

1.8如何设置当前目录和搜索路径，在当前目录上的文件和在搜索路径上的文件有什么区别？

当前目录可以在当前目录浏览器窗口左上方的输入栏中设置，搜索路径可以通过选择操作桌面的 file 菜单中的 Set Path 菜单项来完成。在没有特别说明的情况下，只有当前目录和搜索路径上的函数和文件能够被 MATLAB 运行和调用，如果在当前目录上有与搜索路径上相同文件名的文件时则优先执行当前目录上的文件，如果没有特别说明，数据文件将存储在当前目录上。

1.9在 MATLAB 中有几种获得帮助的途径？

在 MATLAB 中有多种获得帮助的途径：

（1）帮助浏览器：选择 view 菜单中的 Help 菜单项或选择 Help 菜单中的 MATLAB Help 菜单项可以打开帮助浏览器；

（2）help 命令：在命令窗口键入“help”命令可以列出帮助主题，键入“help 函数名”可以得到指定函数的在线帮助信息；

（3）lookfor 命令：在命令窗口键入“lookfor 关键词”可以搜索出一系列与给定关键词相关的命令和函数；

（4）模糊查询：输入命令的前几个字母，然后按 Tab 键，就可以列出所有以这几个字母开始的命令和函数。

注意：lookfor 和模糊查询查到的不是详细信息，通常还需要在确定了具体函数名称后用 help 命令显示详细信息。

2.3在进行算术运算时，数组运算和矩阵运算各有什么要求？

进行数组运算的两个数组必须有相同的尺寸。进行矩阵运算的两个矩阵必须满足矩阵运算规则，如矩阵 a 与 b 相乘（a*b）时必须满足 a 的列数等于 b 的行数。

3.3 极值与最值

求函数极值的流程：求一阶导数 → 令导数为 0 求驻点 → 用二阶导数判断极大/极小。MATLAB 用 solve 解方程，subs 代入求值。

MATLAB — 求极值完整流程
syms x

df = diff(f, x);          % 一阶导 → 3x² - 6x - 9
crit = solve(df, x);      % 求驻点 → -1 和 3
d2f = diff(f, x, 2);      % 二阶导 → 6x - 6
for i = 1:length(crit)
    val = double(subs(d2f, x, crit(i)));
    if val > 0
        fprintf('x=%s 处取得极小值 f=%s\n', crit(i), subs(f,x,crit(i)));
    elseif val < 0
        fprintf('x=%s 处取得极大值 f=%s\n', crit(i), subs(f,x,crit(i)));
    end
end

微分方程与级数

细菌增长、物体冷却、营养降解——这些食品问题都由微分方程描述。dsolve 求解析解，ode45 求数值解。

5.1 常微分方程 dsolve

解析求解用 dsolve。注意写法：导数用 diff(y,t) 或 Dy，初值条件直接作为第二个参数传入。

MATLAB — 一阶微分方程
syms y(t)
% 求解 y' = 2*y，初值 y(0) = 3
eqn = diff(y,t) == 2*y;
cond = y(0) == 3;
sol = dsolve(eqn, cond)
运行结果
sol =
3*exp(2*t)

解释：\(y'=2y\) 是“增长速率与当前量成正比”的模型，解 \(y=3e^{2t}\) 是指数增长——细菌增殖就是这类方程。

示例 2：二阶线性常系数 \(y''-3y'+2y=0\)，\(y(0)=1,\ y'(0)=0\)：

MATLAB — 二阶微分方程
syms y(t)
eqn = diff(y,t,2) - 3*diff(y,t) + 2*y == 0;
cond = [y(0)==1, subs(diff(y,t),t,0)==0];
sol = dsolve(eqn, cond)
运行结果
sol =
2*exp(t) - exp(2*t)
MATLAB 的 == 用来写“方程”而不是赋值。写 diff(y,t) = 2*y 会直接报错；等式必须用 ==。
高阶方程的特征方程法验证：\(r^2-3r+2=0\) 得 \(r=1,2\)，通解 \(y=C_1e^t+C_2e^{2t}\)，代初值得 \(C_1=2,C_2=-1\)，与 MATLAB 结果一致。

5.2 数值解 ode45

很多微分方程没有解析解（比如带复杂非线性项），用 ode45 求数值解：给定时间范围和初值，输出数值点列。

案例 6.1

食品冷却模型：牛顿冷却定律

问题：刚出锅的肉汤温度 90℃，厨房环境温度 20℃。若冷却速率常数 k = 0.05 /min，问 30 分钟后肉汤多少度？降到 40℃ 需要多久？

建模：牛顿冷却定律——物体冷却速率与温差成正比：

\(\displaystyle \frac{dT}{dt}=-k(T-T_a),\qquad T(0)=T_0\)

求解：这是可分离变量的一阶方程，解析解为 \(T(t)=T_a+(T_0-T_a)e^{-kt}\)。用 MATLAB 直接求解：

MATLAB — 冷却模型完整求解
syms T(t) k Ta T0
eqn = diff(T,t) == -k*(T - Ta);
cond = T(0) == T0;
sol = dsolve(eqn, cond)     % T = Ta + (T0-Ta)*exp(-k*t)

% 代入具体数值：T0=90, Ta=20, k=0.05
T30 = double(subs(sol, {k,Ta,T0,t}, {0.05, 20, 90, 30}));  % 30分钟温度
t_cool = double(solve(subs(sol, {k,Ta,T0}, {0.05,20,90}) == 40, t)); % 降到40℃时间
fprintf('30分钟后温度: %.2f ℃\n', T30);
fprintf('降到40℃需要: %.2f 分钟\n', t_cool);
运行结果
sol =
Ta - Ta*exp(-k*t) + T0*exp(-k*t)

30分钟后温度: 45.60 ℃
降到40℃需要: 25.08 分钟

交互演示：拖动滑块改变冷却速率 k，观察温度曲线与“降到 40℃ 所需时间”如何变化。这正是“参数变化 → 结果变化”的数学实验思维。

0.050 降到 40℃ 需 25.08 分钟
图 6-1 冷却曲线 T(t) = 20 + 70·e^(−kt)（交互：拖动滑块改变 k）
绿色虚线标记 40℃ 目标线；曲线与虚线交点横坐标即所需时间。
实验报告写法：建模（写出微分方程与初值）→ 求解（给出 MATLAB 代码）→ 数值结果（30 分钟 45.6℃，25.08 分钟降到 40℃）→ 图像（放冷却曲线图）→ 分析（k 越大冷却越快，降温速率随温差减小而减慢）。
案例 6.2

细菌增殖模型：指数增长与 Logistic

问题：某食品基质中细菌初始数量 100 个，增长率 r = 0.3 /h。（1）若不控制，10 小时后多少？（2）考虑环境容量 K = 10000（Logistic 模型），10 小时后多少？

建模：指数增长 \(\frac{dN}{dt}=rN\)；更符合实际的 Logistic 增长 \(\frac{dN}{dt}=rN\left(1-\frac{N}{K}\right)\)。

MATLAB — 两种增长模型对比
syms N(t) r K
% 指数增长
eq1 = diff(N,t) == r*N;
N1 = dsolve(eq1, N(0)==100)          % 100*exp(r*t)

% Logistic 增长
eq2 = diff(N,t) == r*N*(1 - N/K);
N2 = dsolve(eq2, N(0)==100)

% 代入数值
N1_10 = double(subs(N1, {r,t}, {0.3, 10}));
N2_10 = double(subs(N2, {r,K,t}, {0.3, 10000, 10}));
fprintf('指数模型10小时后: %.0f 个\n', N1_10);
fprintf('Logistic模型10小时后: %.0f 个\n', N2_10);
运行结果
N1 =
100*exp(r*t)

N2 =
1000000/(exp(-(3*t)/10)*(10000 - 100) + 100)

指数模型10小时后: 2009 个
Logistic模型10小时后: 1723 个
图 6-2 指数增长 vs Logistic 增长曲线（网页复现）
指数模型持续加速增长；Logistic 模型受环境容量 K 限制，趋于饱和。
Logistic 的解析解是分式，代入参数时用 subs(N2, {r,K,t}, {...}) 一一对应，顺序不能错。也可以改用 ode45 数值求解更稳妥。
食品意义：指数模型说明“不及时控制，细菌会爆炸式增长”（10 小时从 100 到 2009）；Logistic 说明营养/空间有限时增长会饱和——对应食品保藏中“抑制初始菌数 + 限制营养”的双重策略。
案例 6.3

营养成分降解：一级反应动力学拟合

问题：维生素 C 在储存过程中按一级反应降解：\(C(t)=C_0e^{-kt}\)。实验测得 0、2、4、6、8 天的维生素 C 含量分别为 50、42.4、35.9、30.4、25.8 mg/100g。求降解速率常数 k，并预测 12 天后含量。

思路：对模型两边取对数 \(\ln C=\ln C_0-kt\)，变成直线，用 polyfit 做线性拟合。

MATLAB — 数据拟合求降解速率
t = [0 2 4 6 8];
C = [50 42.4 35.9 30.4 25.8];
p = polyfit(t, log(C), 1);     % 拟合 lnC = p(1)*t + p(2)
k = -p(1)                      % 降解速率常数
C0 = exp(p(2))                 % 初始含量
C12 = C0 * exp(-k*12);         % 12天预测
fprintf('k = %.4f /天, C0 = %.2f, 12天后 = %.2f mg/100g\n', k, C0, C12);
运行结果
k = 0.0811 /天, C0 = 50.04, 12天后 = 18.58 mg/100g

案例 6.4

加工最值问题：产量优化

问题：某食品厂日产量 Q（吨）与生产温度 x（℃）的关系为 \(Q(x)=-0.02x^2+1.2x+10\)，问生产温度取多少时产量最大？最大产量是多少？

MATLAB — 二次函数最值
syms x

x_opt2 = fminbnd(@(x) -(-0.02*x.^2+1.2*x+10), 0, 100);
运行结果
x_opt =
30

Q_max =
    28

解释：生产温度 30℃ 时日产量最大 28 吨。也可用 fplot(Q,[0 60]) 画抛物线，直观看到顶点位置。

8.1 符号运算与表达式

4.1创建符号变量有几种方法？

MATLAB 提供了两种创建符号变量和表达式的函数：sym 和 syms。

sym 用于创建一个符号变量或表达式，用法如 x=sym('x') 及 f=sym('x+y+z')，syms 用于创建多个符号变量，用法如 syms x y z。

MATLAB — 符号变量
f=sym('x+y+z')
% 相当于
syms x y z
f=x+y+z
4.2下面三种表示方法有什么不同的含义？

（1）f=3*x^2+5*x+2

（2）f='3*x^2+5*x+2'

（3）x=sym('x')，f=3*x^2+5*x+2

（1）f=3*x^2+5*x+2 表示在给定 x 时，将 3*x^2+5*x+2 的数值运算结果赋值给变量 f，如果没有给定 x 则指示错误信息。

（2）f='3*x^2+5*x+2' 表示将字符串 '3*x^2+5*x+2' 赋值给字符变量 f，没有任何计算含义，因此也不对字符串中的内容做任何分析。

（3）x=sym('x')，f=3*x^2+5*x+2 表示 x 是一个符号变量，因此算式 f=3*x^2+5*x+2 就具有了符号函数的意义，f 也自然成为符号变量了。

8.2 Simulink 建模与仿真

9.1什么是 Simulink？

Simulink 是一个用来对动态系统进行建模、仿真和分析的软件包，它支持连续的、离散的或二者混合的线性和非线性系统，也支持具有多种采样速率的多速率系统。

9.2如何进行下列操作：（1）翻转模块（2）给模型窗口加标题（3）指定仿真时间（4）设置示波器的显示刻度。
（1）翻转模块

翻转：将鼠标指针指向要翻转的模块并按下鼠标右键，在弹出的菜单中选择 Format 栏中的 Flip Block 项，模块将翻转 180°，每选择一次模块都将翻转 180°，该操作也可以在菜单栏中的 Format 菜单中进行。

（2）给模型窗口加标题

在模型窗口的上方双击鼠标左键，会出现的一个文本输入框，输入文字并通过 Format 菜单中的选项改变字体的颜色和大小，就可以做出一个好看的标题。（在模型窗口的任意地方都可以通过双击鼠标左键后输入文字为模型窗口添加说明）

（3）指定仿真时间

选择 Simulation 菜单打开参数设置对话框，在 Solver 页面中第一项 Simulation time 中通过输入开始时间和结束时间来确定仿真时间。

（4）设置示波器的显示刻度

双击示波器模块弹出示波器显示窗口，在坐标轴区域内的任意位置单击鼠标右键，在弹出的菜单中选择 Axes properties… 菜单项弹出示波器坐标轴属性对话框，可以设置 Y 轴显示的范围。
